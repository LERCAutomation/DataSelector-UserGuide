Recommended user knowledge
==========================

Routine users should understand Windows file handling, MapInfo tables and
maps, and the organisation's reporting data. Basic SQL knowledge is useful
when adapting queries; agreed QSF query files can reduce the amount of SQL
users need to write.

An administrator should understand SQL Server connections and permissions,
the reporting-table refresh process, XML configuration and the relationship
between coordinates, grid sizes and geometry. They should maintain a tested
installation and profiles for users.

Conventions
===========

**Bold text** identifies form labels and buttons. ``Fixed-width text``
identifies settings, filenames and SQL expressions. Menu paths such as
**Tools --> Data Selector --> Run Data Selector** identify a sequence of
choices. Tips, notes and cautions provide additional guidance at the point
where it is needed.
