DataSelector for MapInfo User Guide
==================================

User guide for [DataSelector for MapInfo](https://github.com/LERCAutomation/DataSelector-MapInfo), covering the release recorded in [conf.py](conf.py).

The guide includes a [quick start and worked example](quickstart/quickstart.rst), administrator guidance, SQL examples, downloadable XML profiles, operating instructions and an appendix change log. It is published in HTML and PDF on [Read the Docs](https://readthedocs.org/projects/dataselector-userguide/).

A separate [ArcGIS Pro implementation](https://github.com/LERCAutomation/DataSelector-ArcPro) is available.
